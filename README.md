# TeenPay 💸

A modern digital payment simulation app built using **Flutter** and **Firebase**, designed to mimic real-world UPI and wallet-based transactions with a clean and responsive user experience.

---

# 🚀 Features

- 🔐 Firebase Authentication (Login & Signup)
- 📱 QR Code Based Payments
- ☎️ Send Money via Phone Number
- 💰 Wallet Balance Management
- 📜 Transaction History Tracking
- 🎁 Rewards & Cashback System
- 🙋 Money Request Functionality
- 🔄 Real-time Data Sync using Firebase
- 🎨 Clean and Responsive Flutter UI

---

# 🛠️ Tech Stack

## Frontend
- Flutter (Dart)

## Backend & Database
- Firebase Authentication
- Cloud Firestore / Realtime Database

## Additional Packages
- QR Code Scanner & Generator Packages
- State Management *(Provider / Riverpod / Bloc if used)*

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/TeenPay.git
cd TeenPay
```

## 2️⃣ Install Dependencies

```bash
flutter pub get
```

## 3️⃣ Configure Firebase

- Create a Firebase project
- Add Android/iOS applications
- Download:
  - `google-services.json`
  - `GoogleService-Info.plist`
- Place them in their respective directories

## 4️⃣ Run the App

```bash
flutter run
```
